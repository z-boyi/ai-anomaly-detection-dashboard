# AI Anomaly Detection & Early-Warning Dashboard

## Overview
This project builds an AI-assisted anomaly detection system for monitoring volatile time-series data.
Using unsupervised learning and statistical feature engineering, the system flags unusual patterns
and presents results through an interactive Tableau dashboard for decision-making.

## Use Case
Early detection of abnormal behavior in high-variability metrics such as financial prices, volumes,
or transaction activity.

## Tools
- Python (Pandas, NumPy, scikit-learn)
- Tableau
- Git / GitHub
